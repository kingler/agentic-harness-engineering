Day 1 · Component breakouts

Build your harness, one component at a time

Five short breakouts. One template package across all of them. Pick the app you're reverse-engineering (Harvey, Claude for Financial Services, or Granola), then let Copilot or RooCode walk you through generating each component in your own repo.

Before you start

  • VS Code installed (or a compatible editor).
  • GitHub Copilot extension enabled — Pro / Business / Enterprise plan.
  • RooCode extension installed and signed in.
  • A repo open in VS Code — your team's, or a sandbox is fine.
  • jq on your $PATH for the Rules & Hooks breakout.

Download the template (once)

Same zip covers all five breakouts. The slash commands live inside it under .github/prompts/ (Copilot) and .claude/commands/ (Claude Code / RooCode-compatible).

Download harness-templates.zip ~45 KB

The five breakouts

01

System prompt

Draft AGENTS.md using the five-section anatomy: identity, scope, hard rules, tool roster, failure modes. Slash command: /draft-system-prompt.

 02

Skills

Author a SKILL.md directory with frontmatter trigger + body + bundled scripts/ · references/ · assets/. Slash command: /draft-skill.

 03

Tools

Write a script-as-tool descriptor with WHAT / WHEN / WHEN-NOT, plus an input schema and an executable stub. Slash command: /draft-tool.

 04

Rules & Hooks

Pair settings.json allow / deny / ask with a pre-tool-use.sh hook that enforces it. Slash command: /draft-rules-hooks.

 05

Knowledge & Memory

Write one durable knowledge file plus a session memory scaffold — and learn what stays where. Slash command: /draft-knowledge.
