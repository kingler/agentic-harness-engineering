Component 02 · Skills

Author a SKILL.md

A skill is a directory, not a single file. Walk through the canonical anatomy — frontmatter trigger, body, bundled scripts/ · references/ · assets/ — for the app you picked.

Prerequisites

  • VS Code installed.
  • GitHub Copilot extension enabled (Pro / Business / Enterprise).
  • RooCode extension installed and signed in.
  • You've completed Component 1 — AGENTS.md exists at the repo root.

1Download the template (if you haven't)

Same zip across all five breakouts.

Download harness-templates.zip ~45 KB

2Skill anatomy — the canonical shape

From the Agent Skills spec:

.claude/skills/{skill-name}/
├── SKILL.md          # required entrypoint
├── scripts/         # executable code — RUN, not read
├── references/      # docs loaded on demand
└── assets/          # files used in output (templates, etc.)

Only SKILL.md is required. Everything else is progressive disclosure — loaded only when the body links to it.

3Pick the app + the specialized job

Harvey · candidate skills

  • review-disclosure — flag missing disclosures in an MA filing draft.
  • cite-check — verify every legal citation against the loaded corpus.
  • discovery-tag — apply privilege / responsiveness tags to a doc dump.

Trigger example: "Use when the user asks to review, audit, or check disclosure completeness on a filing draft."

Claude Financial Services · candidate skills

  • trace-numeric-lineage — pin every number in a deliverable back to a source row.
  • draft-disclosure — produce a Reg-FD-aware disclosure from research notes.
  • scenario-build — construct a sensitivity table from a single base case.

Trigger example: "Use when the user asks to trace, audit, or verify the source of any number in a workbook."

Granola · candidate skills

  • summarize-meeting — turn a transcript into a 5-bullet recap.
  • extract-actions — pull only explicit commitments, with owner and due date.
  • followup-draft — write the post-meeting email in the host's voice.

Trigger example: "Use when the user asks to summarize, recap, or extract action items from a meeting."

4Run the slash command

/draft-skill

The agent will walk you through three sections in order:

  1. Description (the trigger). 1–2 lines that finish "Use when the user asks to…". This is what the loader reads to decide whether to invoke. Treat it like UX copy for the loader.
  2. When-to-use + steps. Three bullets + numbered, mechanical steps.
  3. Bundled resources. Will this skill need a script, a reference doc, or an output template?
The corrected definition. Older docs sometimes describe a skill as a single .md file. The current spec is a directory with SKILL.md required + optional scripts/ · references/ · assets/. Keep SKILL.md under 500 lines; push detail into references/.

5Pressure-test the description

Show the description (without the body) to a colleague. Can they predict when Claude should load it? If they can't, the loader can't either. Tighten and re-run.
