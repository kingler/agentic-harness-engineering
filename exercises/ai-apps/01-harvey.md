# Reverse-engineer option A — Harvey

**Product:** [Harvey](https://www.harvey.ai/) — legal AI platform for research, drafting, and document analysis.  
**Best for:** Teams who want the richest **vertical harness** example (privilege, citations, multi-agent workflows).

---

## Quick profile


| Lens                        | What to look for                                                                |
| --------------------------- | ------------------------------------------------------------------------------- |
| **System prompt / persona** | Legal tone, refusal patterns around privilege, jurisdiction-specific caveats.   |
| **Tools & skills**          | Vault / knowledge retrieval, workflow agents (litigation vs transactional).     |
| **Knowledge**               | Firm documents as source of truth — how does the harness keep answers grounded? |
| **Hooks / governance**      | Audit, DLP, deterministic blocks the model cannot negotiate away.               |
| **Memory**                  | What persists per matter vs per user?                                           |
| **Integrations**            | DMS, email, collaboration — MCP-style connectors in practice.                   |


---

## Workshop use

1. Skim the shipped **Harvey** anatomy slide in `Agentic Harness Engineering.html`.
2. In **Breakout 1**, rewrite your template’s system prompt so the agent “thinks” like a legal copilot (still using your repo’s file layout).
3. For **Breakout 2–5**, pick behaviors from the table above and implement the closest local equivalent (e.g. `knowledge/spec-schema.md` → your domain glossary).
