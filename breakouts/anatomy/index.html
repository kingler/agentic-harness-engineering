The six components

01

System prompt

The persistent frame the agent reads every turn. Walks the full AGENTS.md from the sample harness — identity, capabilities, tool roster, never/always rules, escalation.

 02

Skills

A skill is a directory, not a file. Walks SKILL.md — frontmatter as retrieval trigger, body kept short, progressive disclosure via references/.

 03

Tools

The JSON face + executable body. Walks validate_spec.json — name, description (what / when / when-not), input schema, implementation binding.

 04

Rules & hooks

Policy on top, enforcement underneath. Combined page: settings.json (allow / deny / ask) and pre-tool-use.sh (event payload → decision JSON).

 05

Knowledge

The slow tier. Walks spec-schema.md — domain facts the agent reads on demand. Quarterly-stable, not per-turn.

 06

Memory

The fast tier. Walks SESSION.md — working-set bullets, scratch decisions, promotion guardrails. Never secrets.
