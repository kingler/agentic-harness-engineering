Breakout 2 · ~12–15 min

Skills

Skills are specialist prompts loaded on demand — smaller base context, sharper behavior when a trigger matches (keyword, slash command, or semantic routing depending on harness).

Download starter pack (includes skill-creator) View skill-creator/SKILL.md (repo)

Goal

One new skill file: frontmatter (name, rich description with triggers + anti-triggers) + numbered body the agent follows.

How agents use skills

  • The description field is UX copy for routing — write “Use when… / Do NOT use when…”.
  • The body is the checklist executed once the skill loads.
  • Skills chain naturally: stage 1 skill outputs structured JSON → stage 2 skill consumes it (human or orchestrator passes context).
skill-creator After unzipping the starter pack, copy skill-creator/ into your skills directory (or reference it). Invoke it when you want the agent to propose YAML frontmatter, progressive-disclosure sections, and trigger wording — follow SKILL.md inside that folder.

Example placement
