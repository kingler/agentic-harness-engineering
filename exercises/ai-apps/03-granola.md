# Reverse-engineer option C — Granola

**Product:** [Granola](https://www.granola.ai/) — AI meeting notepad (capture, recap, action extraction, tool sync).  
**Best for:** Teams who want the **smallest UX surface** while still mapping **all six harness components** clearly.

---

## Quick profile

| Lens | What to look for |
|------|------------------|
| **System prompt / persona** | Neutral summarizer; avoids inventing commitments; highlights uncertainty. |
| **Tools & skills** | Export to docs/CRM/task systems; different rubrics for meeting types. |
| **Knowledge** | Org glossary, customer dictionary, acronym list — lightweight but high leverage. |
| **Hooks / governance** | Consent / recording / retention — product policy expressed as deterministic gates. |
| **Memory** | Per-meeting ephemeral state vs longitudinal “episode” memory across weeks. |
| **Orchestration** | Live capture vs post-call refinement passes (**skill chains**). |

---

## Workshop use
