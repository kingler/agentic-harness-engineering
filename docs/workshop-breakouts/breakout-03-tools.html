Breakout 3 · ~12 min

Tools (function · script · MCP)

Define exactly one tool your agent would plausibly call for the app you reverse-engineered. JSON declares the contract; a script or MCP server performs work.

Starter pack (example JSON + commands)

Goal

tools/<name>.json with name, parameters, and a three-sentence description (what / when / when not). If script-backed, stub scripts/<name>.sh that prints JSON to stdout.

Tips

  • Fewer tools beats many vague ones — each extra tool taxes context every turn.
  • Reuse patterns from exercises/sample-harness-uxd-specs/tools/validate_spec.json.
  • MCP is optional — declare only if you already have a server handy.
